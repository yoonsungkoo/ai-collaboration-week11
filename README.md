
# CSV 성적 처리 프로그램 테스트

## ① What — 무엇을 하는 프로그램인가?
CSV 파일에서 학생 이름과 점수를 읽어 유효한 데이터와 건너뛴 데이터를 구분하는 프로그램이다.

## ② Why — 왜 만들었는가?
이 프로그램은 CSV 파일에 저장된 학생들의 점수 데이터를 읽고,
유효한 데이터와 제외할 데이터를 구분하는 과정을 구현하기 위해 만들었다.
또한 직접 작성한 테스트와 AI가 생성한 테스트를 비교하면서
테스트 설계 방식에 따라 검증 결과가 어떻게 달라지는지 확인하고자 했다.

## ③ How — 설치 및 실행 방법

### 필요한 프로그램
- Python 3.14
- pytest 9.2.0
- pytest-cov 7.1.0

### 설치 명령어
```powershell
python -m pip install pytest pytest-cov
```

### 프로그램 실행
```powershell
python load_scores.py scores.csv
```

## ④ 테스트 — pytest 실행 방법과 결과

### 직접 작성한 테스트
```powershell
python -m pytest test_load_scores.py -v
```

실행 결과: 12 passed

### 코드 커버리지 확인
```powershell
python -m pytest test_load_scores.py --cov=load_scores --cov-report=term-missing
```

실행 결과: 커버리지 80%

## 12주차 실습: AI와 함께 데이터 분석하고 검증하기

### 데이터

- 데이터 출처: 12주차 실습에서 교수님이 제공한 scores_2026.csv
- 원본 데이터 크기: 114행 5열
- 정제 후 데이터 크기: 100행 5열

### 열 설명

| 열 이름 | 설명 |
|---|---|
| 학번 | 학생을 구분하는 식별번호 |
| 이름 | 학생 이름 |
| 반 | 학생의 소속 반 |
| 과목 | 시험 과목 |
| 점수 | 학생의 시험 점수 |

### 데이터 정제 방법

1. 점수가 비어 있는 행 6개를 삭제하였다.
   - 점수가 없는 데이터는 평균 계산에 사용할 수 없기 때문이다.
2. 모든 열이 동일한 중복 행 4개를 삭제하였다.
   - 중복된 데이터가 평균 계산에 반복 반영되는 것을 방지하기 위해서이다.
3. 반과 과목 이름의 앞뒤 공백을 제거하였다.
   - 동일한 반이나 과목이 서로 다른 그룹으로 분류되는 것을 방지하기 위해서이다.
4. 점수가 0~100 범위를 벗어난 행 4개를 삭제하였다.
   - 유효하지 않은 점수가 분석 결과에 영향을 주는 것을 방지하기 위해서이다.

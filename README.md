
# CSV 성적 처리 프로그램 테스트

## 1. 프로젝트 소개
CSV 파일에서 학생 이름과 점수를 읽고, 유효한 데이터와 건너뛴 데이터를 구분하는 프로그램을 pytest로 테스트한 프로젝트이다.

## 2. 주요 파일
- `load_scores.py`: CSV 성적 처리 프로그램
- `test_load_scores.py`: 직접 작성한 테스트
- `test_ai_A.py`: AI에 구현 코드를 제공하여 생성한 테스트
- `test_ai_B.py`: AI에 명세를 제공하여 생성한 테스트
- `bug3_logic.py`: 논리 오류가 포함된 실험용 코드
- `test_bug3_logic.py`: 논리 오류 검출을 위한 AI 테스트

## 3. 실행 환경
- Python 3.14
- pytest 9.2
- pytest-cov 7.1

## 4. 테스트 실행 방법
프로젝트 폴더에서 다음 명령어를 실행한다.

```powershell
python -m pytest test_load_scores.py -v
python -m pytest test_ai_A.py -v
python -m pytest test_ai_B.py -v
python -m pytest test_bug3_logic.py -v
```

## 5. 테스트 결과
| 구분 | 통과 | 실패 | 커버리지 |
|---|---:|---:|---:|
| 직접 작성 | 12 | 0 | 80% |
| AI 실험 A | 18 | 0 | 80% |
| AI 실험 B | 1 | 14 | 78% |
| 논리 오류 검출 | 5 | 5 | 측정하지 않음 |

AI 실험 B의 실패는 제공한 명세와 현재 구현의 반환 형식 및 헤더 처리 방식이 달랐기 때문에 발생하였다.

논리 오류 검출 실험의 실패 5개는 기존 코드에 포함된 오류를 발견한 결과이다.

## 6. 실험 결과 및 배운 점
코드를 제공한 AI 실험 A에서는 모든 테스트가 통과했지만, 명세를 제공한 실험 B에서는 명세와 구현의 차이로 여러 테스트가 실패하였다.

별도의 논리 오류 검출 실험에서는 최댓값 계산 범위와 합격 기준의 부등호 오류를 발견하였다.

이를 통해 테스트의 통과 개수나 코드 커버리지뿐 아니라 명세와 경계값을 정확히 검증하는 것이 중요하다는 점을 배웠다.
